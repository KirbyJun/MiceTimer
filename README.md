# MiceTimer v2.0

**MiceTimer** 是一款面向实验室的行为学实验计时/计数辅助工具，基于 PySide6 构建。  
v2.0 起支持 **分级界面**：范式 → 分组（对照组/实验组）→ 实验对象 → 项目计时/计数。

---

## 支持的范式

| 范式 | 计时项 | 计数项 | 汇总计算 |
|------|--------|--------|----------|
| **3-SIT**（三箱社交） | Mice/s, Toy/s | — | Mice-Toy/s, Mice+Toy/s, DI |
| **Free-SIT**（自由社交） | 适应时间/s, 嗅探时间/s | 躲避次数 | — |

### 3-SIT 计算公式
- **Mice-Toy/s** = Mice/s − Toy/s  
- **Mice+Toy/s** = Mice/s + Toy/s  
- **DI** = (Mice-Toy/s) ÷ (Mice+Toy/s)，保留 6 位小数；分母为 0 时显示空白

### 计时单位
所有计时值均以 **秒（ss.00）** 显示，例如 `12.34` 表示 12.34 秒。  
导出 Excel 与界面显示格式一致。

---

## 主要功能

- **分级界面**：范式选择 → 汇总表（对照组/实验组 → 实验对象行）→ 对象详情页（计时/计数操作）
- **3-SIT 汇总表**：自动计算差值、和、DI（6 位小数）
- **Free-SIT 汇总表**：适应时间/s、嗅探时间/s、躲避次数
- **快捷键控制**（窗口聚焦时生效）：
  - F5 — 开始/暂停实验
  - F6 — 重置当前对象
  - F7 — 导出到默认目录
  - 数字键 1~9 — 控制对应编号的项目计时/计数
- 自动保存与恢复（`data/autosave/recovery.json`）
- 模板保存/加载（`data/templates/`）
- 导出 Excel（默认目录或另存为）
- 事件日志

## 分级界面使用说明

### 1. 选择范式
在汇总页顶部下拉框选择 **3-SIT** 或 **Free-SIT**。  
> ⚠️ 切换范式会清除当前所有实验对象数据，请先导出或另存。

### 2. 添加实验对象
- 汇总表中，每个组（对照组/实验组）标题行右侧有 **「+ 添加对象」** 按钮。  
- 点击后输入对象名称（如 `B21`），即可在该组添加一行。

### 3. 删除实验对象
- 点击对象行右侧的 **「删除」** 按钮，会弹出二次确认对话框防止误删。

### 4. 进入对象详情（计时/计数）
- 点击对象行右侧的 **「详情」** 按钮，打开该对象的计时/计数操作窗口。
- 操作窗口显示该对象的所有项目（Mice/s、Toy/s 等），可：
  - 点击 **「开始实验」** 启动计时（快捷键 F5）
  - 点击项目行的 **▶/⏸** 或按 **数字键 1~9** 控制对应项目
  - 点击 **「← 返回汇总表」** 返回，数据自动同步到汇总表

### 5. 汇总表实时更新
对象详情窗口打开期间，汇总表也会实时显示当前计时值。

## 本地运行

### 前提

- Python 3.10 或更高版本（推荐 3.11+）
- Windows / Linux / macOS（快捷键仅在窗口聚焦时生效）

### 步骤

```bash
# 1. 克隆仓库
git clone https://github.com/KirbyJun/MiceTimer.git
cd MiceTimer

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行程序
python main.py
```

---

## 打包（Windows）

双击或在命令行运行：

```bat
build.bat
```

打包完成后，可执行文件位于：

```
releases\MiceTimer_vX.Y.Z\MiceTimer.exe
```

## 常见问题

### 导出的 Excel 在哪里

默认导出路径：`<程序所在目录>\data\export\`  
也可点击「另存为...」手动选择保存位置。

### 导出表格布局

导出的 Excel 与统计分析工具（如 SPSS/GraphPad）兼容，按批次区块纵向输出：

**工作表结构（每个批次一块）：**

```
行 1  [合并居中标题]  <备注或日期>-<范式>   例：5-6w-Free-SIT
行 2  [列标题行，加粗] ""  | 列1  | 列2  | …
行 3  [对照组标题行，绿底白字，合并] 对照组
行 4+ 对照组实验对象数据行（每行一只鼠）
行 N  [实验组标题行，蓝底白字，合并] 实验组
行 N+ 实验组实验对象数据行
(空行)  批次区块结束
```

**Free-SIT 列结构（4 列）：**

| A（对象名） | B（适应时间/s） | C（嗅探时间/s） | D（躲避次数） |
|------------|----------------|----------------|--------------|
| B21        | 45.12          | 32.50          | 3            |

**3-SIT 列结构（6 列）：**

| A（对象名） | B（Mice/s） | C（Toy/s） | D（Mice-Toy/s） | E（Mice+Toy/s） | F（DI）       |
|------------|------------|-----------|----------------|----------------|---------------|
| B21        | 120.50     | 80.25     | 40.25          | 200.75         | 0.200498      |

- 所有计时值以数值格式（`0.00`，即秒制两位小数）写入单元格，方便直接参与统计计算  
- DI 以 6 位小数格式（`0.000000`）写入；分母为 0 时该单元格留空（不报错）  
- 批次标题 = 「备注」字段（若填写）或会话「日期」+ 范式名，例如 `5-6w-Free-SIT`

### 旧版本数据能否兼容加载

v2.0 会自动识别旧版（v1）格式并迁移：
- 旧版范式名（三箱社交/自由社交）自动映射到新名（3-SIT/Free-SIT）
- 旧版项目名（学习小鼠与真鼠社交的时间 → Mice/s；与玩具社交的时间 → Toy/s）自动重命名
- 旧版实验数据作为「对照组」下的第一个实验对象导入

### 杀软误报 / 被拦截

PyInstaller 打包的单文件 exe 可能触发杀软启发式检测。  
解决：将程序添加到杀软白名单，或使用源码直接运行（`python main.py`）。
